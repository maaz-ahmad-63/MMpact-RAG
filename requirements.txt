# -- LangChain agent (app/graph/) -------------------------------------------
# langchain-core ONLY: @tool, the message types and BaseChatModel/bind_tools.
#
# Deliberately NOT `langchain` and NOT langchain-<provider>. Measured:
#     pip install --dry-run langchain langchain-groq
#     -> Would install groq-0.37.1 langchain-1.3.15 langchain-core-1.5.6
#                      langchain-groq-1.1.3 langgraph-1.2.11
# `langchain` drags in langgraph, and langchain-groq would replace the pinned
# groq 0.15.0 that /agent/reply runs on. app/graph/chat_model.py therefore
# adapts the EXISTING services/llm providers to LangChain's interface instead,
# which also keeps their bounded timeouts, reasoning/thinking controls and
# require_model() guard.
